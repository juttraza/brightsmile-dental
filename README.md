# BrightSmile Dental (portfolio demo)
Vite + TypeScript + GSAP (ScrollTrigger) + Lenis.
- `npm install` then `npm run dev` (local preview)
- `npm run build` (typecheck + single-file build in dist/)
- Deploy: push to GitHub, import the repo in Vercel or Netlify (build: `npm run build`, output: `dist`).
All clinic details, reviews and the form are fictional demo content; the form sends/stores nothing.
